# fysiki-b-exams
Προσομοιώσεις εξεταστικής — Φυσική Β΄ Λυκείου Προσανατολισμού (νεο επικεντρο).

- `index.html?exam=kef1` — το διαγώνισμα του Κεφαλαίου 1 (ένα αρχείο `exams/kefN.js` ανά κεφάλαιο).
- Τα `exams/*.js` περιέχουν **μόνο** εκφωνήσεις. Οι σωστές απαντήσεις και η βαθμολόγηση βρίσκονται στο Google Apps Script
  (δεν ανεβαίνουν στο GitHub).
- `config.js` — η διεύθυνση του Apps Script web app.
- Κάθε υποβολή: βαθμολογείται, γράφεται σε Google Sheet και στέλνεται email στον καθηγητή. Μία υποβολή ανά μαθητή.
- Σε όλους τους υπολογισμούς g = 10 m/s².
